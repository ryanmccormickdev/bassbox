# enclosure

The pedal's printed enclosure (a lid, a base and two optional spacers), written as a program
rather than drawn by hand: [build123d](https://github.com/gumyr/build123d) 0.13.0 builds the
parts from one file of numbers, and tests and a clash check against models of the bought parts
guard them. [DESIGN.md](DESIGN.md) explains the design and the decisions.

Outer size 116.44 x 66.14 x 48.5 mm. The Pi 4 sits upside down under the 4.0" display, with every
Pi port reachable on the sides and the two 1/4" jacks exiting through opposite long sides near the
jack end. The lid and base split at the Pi's top face and snap together.

## What is here

| Path | What |
|---|---|
| `exports/stl/` | `lid.stl`, `base.stl`, `spacer.stl`, in print orientation |
| `exports/3mf/pedal-plate.3mf` | one plate: lid, base and two spacers |
| `exports/step/` | `enclosure-installed.step` (the three printed parts in the box frame), `pedal-assembly.step` (the same with simplified models of the display, Pi, HAT, jacks and screws) |
| `print-profiles/prusa-xl/`, `print-profiles/prusa-mk39s/` | clear-PETG PrusaSlicer profile (`.ini`) and the sliced plate as a PrusaSlicer 3MF project with the settings inside: the plate on a Prusa XL, and the base alone on a Prusa MK3.9S |
| `renders/` | PNG renders: each part in print and installed pose, the closed box, eight cross-sections, the assembly, exploded and translucent views |
| `reports/enclosure-report.json` | the check results and the Ender-3 slice estimate |
| `cad/gen/pedal/` | the generator: `dims.py` (every shared number), `enclosure.py` (the printed parts and their checks), `components.py` (models of the bought parts), `assembly.py` (clash harness, renders, assembly STEP), `__main__.py` (exports, checks, slicing), `xl.py` and `mk39s.py` (the Prusa profiles) |
| `cad/gen/{checks,features,export,slicer,ender}.py` | helpers copied from a larger CAD repository; `export.py` is trimmed to what the pedal uses |
| `cad/slicer/` | the flattened PrusaSlicer profile that `ender.py` slices with |
| `tests/` | 41 tests; the 39 that do not need the vendor HAT mesh run by default |

## Print settings

- **First slice** (PrusaSlicer 2.9.6, Creality Ender-3 V2 Neo profile): PETG, 0.20 mm layers,
  4 walls, 5 top and bottom layers, 40 % gyroid, no supports, one 220 x 220 bed with all four
  pieces: 7 h 30 min, 63.0 g.
- **Clear PETG on a Prusa XL** (`print-profiles/prusa-xl/`): PrusaSlicer's own XL, `0.15mm
  STRUCTURAL` and `Generic PETG` presets with these changes. Clear PETG shows whatever is inside a
  wall, so the walls are all perimeters (5 x 0.45 fills the 2.0 mm walls) and the thin floor and
  bezel print solid: 5 perimeters, 7 top and bottom layers, 100 % rectilinear infill, outer wall at
  30 mm/s and inner walls at 60, nozzle 245 C (first layer 240), bed 80 C (first layer 85), fan
  20 to 40 %.
- **Base alone on a Prusa MK3.9S** (`print-profiles/prusa-mk39s/`): the same overrides on the
  MK3.9S presets, made as a reprint of the base.

## Regenerate

Python 3.12 or newer. The mesh files below regenerated byte for byte with build123d 0.13.0 (OCP
8.0.1.1.0) on macOS, arm64.

```
cd enclosure
uv sync                                    # or: pip install build123d==0.13.0 lib3mf trimesh numpy pyvista pytest
python -m cad.gen.pedal --no-slice         # geometry, checks, renders, clash check -> out/pedal/
python -m cad.gen.pedal.assembly           # assembly renders and pedal-assembly.step -> out/pedal/
python -m pytest                           # 39 pass, 2 skipped without the vendor mesh
```

Slicing needs PrusaSlicer (macOS: `brew install --cask prusaslicer`, or set `PRUSASLICER` to the
binary). Without `--no-slice`, `python -m cad.gen.pedal` slices the plate for the Ender-3 V2 Neo and
runs a support probe on each part; `python -m cad.gen.pedal.xl` and `python -m cad.gen.pedal.mk39s`
rebuild the Prusa profiles from PrusaSlicer's bundled presets. Those slicing steps were not re-run
for this copy; the committed profiles and 3MF projects are the originals.

The HAT's 3D model from RaspiAudio (`3D_UltraMIC4layer_2026-03-18.obj`) is not included. If it is
placed in `scratch/pedal/`, two more tests run and the renders draw the real HAT; without it the
HAT is a set of boxes derived from that model and embedded in `components.py`.
