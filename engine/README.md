# engine

The pedal's real-time audio engine and its effect library, in C++17.

| Target | What |
|---|---|
| `bassbox-engine` | the engine: ALSA full duplex on `hw:wm8960soundcard`, an audio thread pinned to CPU3, a control thread (JSON socket, presets, jack sense, tuner), autosave. `--null-audio` runs everything without hardware. |
| `bb-render` | renders a WAV through a chain offline with the same host and processor code: `bb-render --preset presets/factory/grit.json in.wav out.wav` |
| `bb-catalog` | writes `catalog.json`, the effect catalog (the UI lays out its screens from it until the engine answers) |
| `bb-selftest` | 47 host checks, no audio hardware needed |

Design: [`docs/architecture.md`](../docs/architecture.md) (threads, chain edits, socket protocol),
[`docs/realtime.md`](../docs/realtime.md) (measurements).

## Layout

- `include/effect.h`: the effect interface, a mono in-place block processor.
- `src/`: the host. `processor.*` (audio side), `host.*` (control side), `alsa_audio.cpp`,
  `null_audio.cpp`, `server.cpp`, `presets.cpp`, `jacks.cpp` (libgpiod), `tuner.cpp` (YIN),
  `rt.h` (lock-free rings, denormal control), `selftest.cpp`.
- `effects/`: 33 effects, one `.cpp` each, in nine categories. Dynamics: gate, compressor,
  limiter. Drive: overdrive, distortion, fuzz, octave fuzz, bitcrusher. Amp: amp, cab, neural amp.
  Filter: envelope filter, wah, synth filter. EQ: 3-band, 7-band graphic, low/high cut.
  Modulation: chorus, flanger, phaser, tremolo, vibrato, Uni-Vibe, ring mod. Pitch: octaver,
  pitch shifter, sub synth. Time: delay, tape echo, reverb, shimmer. Utility: boost, looper.
  `effects/README.md` explains how to add one.
- `tests/`: the effect test harness (`fxtest`), plots, and `results/` (recorded output).
- `catalog.json`: generated by `bb-catalog`.

## Build

```
engine/third_party/fetch.sh                       # nlohmann/json, NeuralAmpModelerCore, Eigen
cmake -S engine -B engine/build && cmake --build engine/build -j4
engine/build/bb-selftest
```

`third_party/README.md` lists the three dependencies, their licences and the one patch. On Linux
the real engine also needs `libasound2-dev` and `libgpiod-dev` (version 2); without them it
builds with only `--null-audio`, and without the jack-sense GPIO. On the Pi, `scripts/setup.sh`
builds and installs it. Building `bb-catalog` rewrites `engine/catalog.json`; pass
`-DBB_WRITE_CATALOG=OFF` to skip that.

The Neural Amp effect needs `.nam` model files, which are not included.

To run it without hardware, for example on a Mac (socket paths are limited to 104 characters there,
so use a short one):

```
engine/build/bassbox-engine --null-audio --socket bb.sock --state-dir /tmp/bb --factory-dir presets/factory &
python3 scripts/bbctl.py --socket bb.sock state
```

## Tests

```
python3 scripts/make_test_signals.py riff samples/test-bass-riff.wav     # the synthetic bass riff (11 s) the tests use
make -C engine/tests test                                                # every effect, every corner; add FAST=1 for a quick pass
make -C engine/tests presets bench                                       # factory presets through the riff; CPU per block
make -C engine/tests probe plots                                         # spectra and response plots (numpy + matplotlib)
engine/tests/bbrender_check.sh engine/build/bb-render                    # every effect and preset through bb-render
```

The riff is generated by `scripts/make_test_signals.py` (a plucked-string additive model with a
fixed random seed), so it is not stored in the repository. Without it the harness falls back to a
built-in synthetic riff.

`tests/results/` holds what the suite produced:

- `report.md`: 33 effects, 0 failures, 6 warnings (regenerates byte for byte with `make test`).
- `presets.md`: the factory presets through the riff.
- `cpu.md` and `bb-render.md`: CPU per 64-frame block, recorded on the Pi 4.
- `plots/`: harmonic spectra of the drive effects, cab and EQ responses, modulation and
  reverb-decay plots, regenerated from the code in this folder.
